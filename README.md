# Daytrading-Assistent – Updates

Hier liegen nur die fertigen Versionen (`Daytrading-Assistent.exe`) als **Releases**.
Die App prüft beim Start automatisch, ob es hier eine neuere Version gibt, und installiert sie auf Knopfdruck.

- Jede Version hat eine Prüfsumme (`.sha256`) – die App lädt nur, wenn sie stimmt.
- Deine Daten (Journal, Historie) liegen in `Dokumente\Daytrading-Assistent` und bleiben bei Updates erhalten.

Analyse-Tool, keine Anlageberatung.
